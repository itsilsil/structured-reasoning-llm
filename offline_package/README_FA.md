بسته آفلاین پژوهش

برای اجرای داشبورد، offline_dashboard.html را با Chrome، Edge یا Firefox باز کنید. اینترنت، Python، Streamlit و حساب GitHub لازم نیست.

محتویات: داشبورد تعاملی، خلاصه CSV، داده خام JSONL، تنظیمات اجرا و گزارش Markdown.

محدودیت علمی: ToT-inspired نسخه ساده‌شده تولید چند candidate و داوری با همان مدل است، نه پیاده‌سازی کامل Tree of Thoughts. نتایج فقط مربوط به نمونه ارزیابی‌شده GSM8K هستند.
